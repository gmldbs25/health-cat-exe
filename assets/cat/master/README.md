# nag_cat Character Master

Official project/character name: `nag_cat` (내그캣)

Character nickname: **Nagi** (나기)

The character sheet in this directory is the visual master reference for all future cat poses, states, animations, tray/icon variants, and generated assets. New artwork should preserve Nagi's body proportions, face, fur colors/patterns, line style, shading, collar/tag, and overall soft 2D chibi feel.
